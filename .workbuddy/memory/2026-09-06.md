## GitHub 推送环境踩坑（可复用经验）
- 本环境无 `gh` CLI；SSH 22 与 443 端口均被封 → 只能走 HTTPS。
- 该 GitHub 账号 `settings/tokens/new`（经典 PAT）返回 **404**：新账号无法创建 classic PAT，须用 **fine-grained PAT**（`settings/personal-access-tokens/new`）。
- Fine-grained PAT：勾 **Repository permissions → Contents = Read and write** 可 push 到已存在的公开仓库；但**不能通过 API `POST /user/repos` 创建新仓库**（fine-grained 无建仓权限）。建仓需用户在 GitHub 网页手动完成。
- 用户本机未安装 Git（PowerShell 报 `git 无法识别`）。最终从 WorkBuddy 沙盒用 fine-grained PAT push 成功。
- Fine-grained PAT **无法用 API 自吊销**：`GET /user/personal_access_tokens` 对该 token 作用域返回 404 → 须用户在网页 Settings → Developer settings → Personal access tokens → Fine-grained 里手动 Delete。
- 令牌安全：命令输出用 `sed -E 's#https://[^@]*@github#https://***@github#g'` 脱敏；push 后用 `git remote set-url origin https://github.com/...` 清除 remote 中的令牌。
