四条最值得记住的联系：
① 运算符 → 条件判断与循环：比较运算（>、==、in）和逻辑运算（and / or / not）负责问出 True / False，if 负责按答案决定走哪条路——两者原本就是同一件事的两半。
② 列表与字典 → 文本的数字化：第 3 次课手写的「词频统计」，就是词袋模型（Bag of Words）的手工版，换成库函数只是省事，原理完全一样。
③ 分词与 Token → 文本分析流水线：中文要先分词、大模型要先切 token，看似两件事，其实是同一个问题的两个尺度。
④ 情感分析 → 大模型 API：情感分析的三条路线（词典法 / 机器学习法 / 大模型法）不是替代关系，而是成本、可解释性、效果三者的不同取舍。
