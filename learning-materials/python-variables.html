Python 变量与数据类型

变量是贴在数据上的「名字标签」，数据类型决定了这份数据能做什么、不能做什么。

生成日期：2026-09-17 · 学习视角：Python 零基础入门（第 1 次课） · 资料来源均为公开可核查链接

01学习目标

  • 能用自己的话说清楚「变量」到底是什么——它不是装东西的盒子，而是贴在数据上的名字。
  • 能区分 Python 的四种基本数据类型（int / float / str / bool），并说出各自适合存什么。
  • 能写出一个用 input() 读取用户输入、用 f-string 输出一句话的小程序，并知道为什么必须做类型转换。

02核心问题

  • 为什么 Python 写变量时不用声明类型（不像 C 语言那样写 int age = 20）？这样设计的好处和代价分别是什么？
  • input() 从用户那里拿到的为什么永远是一段文字？不做类型转换会引发什么后果？
  • 在 Python 眼里，3 和 "3" 到底差在哪里？为什么这个差别会让程序当场崩掉？

03个人解释

我的理解：

我以前的印象是「变量就像一个盒子，把数字装进去」。学完之后我理解得更准确了：Python 里的变量更像是贴在数据上的一个名字标签。写 age = 20，并不是「把 20 放进 age 这个盒子里」，而是「给 20 这份数据贴上一个叫 age 的标签」。想通这一点之后，很多东西就顺了——比如为什么同一个变量可以先指向数字、后来又改成一段文字，Python 完全不介意：它只是把标签撕下来，贴到了另一个东西上。

第二个让我印象深刻的点是 input()。我原本以为「输入什么就是什么」，直到写名片生成器时发现：输入 20，程序却把年龄当成文字，age + 1 直接报错。原来 input() 不管用户敲的是什么，一律按字符串（文字）交给你，要参与计算必须自己用 int() 转一次。这个小坑让我第一次真切地感觉到：「类型」不是教科书上的名词，是会让程序当场跑不起来的实在东西。

作为 Python 零基础的大二学生，这次是我第一次写出能和真人对话的程序。最大的收获不是记住了四种类型，而是明白了「报错不是失败，是提示」——NameError 告诉我变量还没定义，TypeError 告诉我类型用错了。读懂报错比背语法更有用。接下来我要用这些基础去写第 2 次课的猜数字游戏。——杨国美

04核心机制 / 组成

Python 最常用的四种基本数据类型，可以先按「它存的是什么」来记：

类型中文例子典型用途
int整数20、-5、0年龄、计数、第几条
float浮点数（带小数）3.14、0.5、2.0概率、比例、有小数的量
str字符串（文字）"你好"、'20'一句话、一个词、一篇文章
bool布尔值True、False判断的结果：是 / 否

机制一：动态类型。Python 不要求你提前声明变量是什么类型。变量的类型由它当前指向的那份数据决定，而且可以随时改变 [来源 1]：

age = 20      # age 现在指向一个整数
age = "二十"  # 同一行标签，改贴到字符串上，Python 不报错

这是「灵活」和「危险」的一体两面：写起来快，但类型用错时错误往往要到运行时才暴露。

机制二：类型转换。需要把数据从一种类型变成另一种时，用同名的内置函数 [来源 4]：

写法结果什么时候会用到
int("20")整数 20把用户输入的文字变成能做加减的数字
str(20)字符串 "20"把数字拼进一句话里
float("3.14")浮点数 3.14处理带小数点的输入
bool(0)False把「有 / 没有」转成真 / 假

机制三：f-string 拼接。把变量的值嵌进一句话里，最直观的写法是在引号前加一个 f，然后用花括号包住变量名 [来源 1]：

name = "杨国美"
age = 20
print(f"你好，{name}，你今年 {age} 岁")  # 你好，杨国美，你今年 20 岁

花括号里可以放变量，也可以直接放算式，例如 f"明年 {age + 1} 岁"。这比用 + 把字符串和数字硬拼起来安全得多——后者一旦忘了转换类型就会报错。

05应用场景

第 1 次课要交的成品是「个人名片生成器」：程序依次问你名字、年龄、城市，然后打印一句自我介绍。完整代码如下：

name = input("请输入你的名字：")
age = int(input("请输入你的年龄："))  # 关键：把文字转成整数
city = input("请输入你所在的城市：")

print(f"你好，{name}！你今年 {age} 岁，来自 {city}。")
print(f"明年你就 {age + 1} 岁了。")
  • 如果不写 int()：age 会是字符串，最后一行的 age + 1 会抛出 TypeError，程序直接停住。这是新手最常撞的坑。
  • 如果名字里带数字（比如「王二」）：完全没问题，因为名字本来就该是文本，不需要转换。

这段代码的骨架——拿到一段输入 → 存进变量 → 处理 → 输出——会在后面反复出现。到了第 12 次课调用大模型 API 时，你会发现结构几乎没变，只是把最后的 print() 换成了「把文字发给模型」。

06易混淆 / 使用边界

容易混淆的点说清楚
3 和 "3"前者是数字，能参与算术；后者是字符串，"3" + 1 会报错，而 "3" + "4" 得到的是 "34"（拼接，不是加法）[来源 1]
= 和 === 是赋值（贴标签），== 是判断是否相等（得到一个 bool）。两者完全不同，写混了不会报错但逻辑全错
input() 的返回类型永远返回字符串。哪怕用户输入的是 20，你拿到的也是 "20"，参与计算前必须先 int() 或 float()
变量命名规则只能由字母、数字、下划线组成，不能以数字开头，不能使用关键字（如 if、for、class）；区分大小写，Age 和 age 是两个不同的变量 [来源 3]
bool 和数字的关系在 Python 里 True 等价于 1、False 等价于 0，所以 True + 1 会得到 2。知道即可，不要依赖这个特性，会让代码难读
浮点数的精度0.1 + 0.2 得到的是 0.30000000000000004 而不是 0.3。这是所有语言的通病，需要精确计算时要用 decimal 模块 [来源 2]

什么时候「不该用」这套简单的变量？当你要处理成百上千条数据时（比如一篇文章里的几万个词），把每个词都单独存一个变量是不现实的。那时需要的是列表和字典——那是第 3 次课的内容。
