Concept Learning Card

情感分析（Sentiment Analysis）

让机器判断一段文本"表达的是正面、负面还是中性情绪"的任务。它有三条主流路线——词典法、机器学习法、大模型法，而同一句话用三种方法很可能得出不同结论。

生成日期：2026-09-17 · 学习视角：大二学生第一次系统接触 AI · 资料来源均为公开可核查链接

01学习目标

  • 能用自己的话说清情感分析到底在预测什么，并区分文档级 / 句子级 / 方面级三种分析粒度。
  • 能对比词典法、机器学习法、大模型法三条路线的原理、数据需求、成本与典型失效场景。
  • 遇到"同一句话三种方法给出不同标签"时，能解释为什么，并说清自己会怎么选路线。

02核心问题

  • 情感分析预测的到底是"作者的真实情绪"，还是"这句话表面的褒贬"？两者什么时候会打架？
  • 词典法为什么既"简单可解释"又"特别容易翻车"？它到底缺了什么信息？
  • 三条路线各自的"入场券"是什么——词典、标注数据，还是 API 预算？
  • 如果三套方法给出三个不同答案，我该信谁？怎么决定最终采信哪一个？

03个人解释

我的理解：

学之前我以为情感分析就是"'好'是正面、'差'是负面"，查个词表就能干。学完我认为它更像一门"猜语气"的手艺：机器看不到表情、听不到语气，只能从字面去反推说话人到底高不高兴。所以难的不是认识词，而是处理那些"字面"和"意思"对不上的句子。

让我改观最大的是三条路线其实是在做三种不同的取舍，不存在"哪个最好"：词典法像一本情绪字典——翻开就查、结果能解释，但它只会查词，遇到"绝了"（本来夸人，这里骂人）就彻底没辙；机器学习法像一个看过几千条评论的学生——它从数据里学到了语境和搭配，但为什么这么判，它自己说不清；大模型法像一个见多识广但有点随性的专家——你几乎不用喂标注数据，写清规则它就懂，可它贵、慢，而且同一句话问两遍可能给你两个答案。

我现在会把"同一句话三种结论"当成正常现象而不是 bug：因为三者看的根本不是同一个东西——一个只看词，一个只看训练数据里的统计规律，一个看整句语义和常识。想清楚"我到底需要多准、多快、多可解释"，路线自然就选出来了。

这学期是我第一次系统接触 AI 和自然语言处理。以前觉得"AI 判情绪"很玄，现在觉得它其实特别"诚实"——你把一句话的褒贬拆开看，就会发现机器判错的地方，往往正是人类也要愣一下的地方（比如反讽、比如"好得我无话可说"）。这让我不再迷信"模型一定比我准"，也不再轻视"规则方法很土"：我们校园二手平台那种每天几千条短评的场景，用词典法先兜底、关键品类再上模型，可能比一上来就堆大模型更划算。学会按场景取舍，比我背下三条路线的定义有用得多。——杨国美

04核心机制 / 组成

① 先搞清楚"分析粒度"，否则三条路线比不到一起去。

粒度它在回答什么例子
文档级 Document-level整篇文本整体是正面还是负面"这条知乎回答整体偏负面"
句子级 Sentence-level单句话的极性"『物流很快』是正面，『包装破了』是负面"
方面级 Aspect-based对某个具体方面的情感"这家店：价格正面、售后负面"

一句话记忆法：文档级看整体、句子级看单句、方面级看"对谁"。现实中做产品分析，方面级几乎是最有用的，因为"整体 3.8 分"没法指导你改什么。

② 三条路线：它们看的东西完全不同。极性（polarity）指正/负/中性这个方向，强度（intensity）指情绪有多浓——两个词白话讲就是"往哪儿偏"和"偏多重"。

路线它到底在看什么需要什么强在哪弱在哪
词典法
Lexicon-based		 查情绪词表（每个词预先打上 −4 到 +4 的分），再叠加否定词、程度副词、感叹号等规则 [来源 1][来源 2] 一部情绪词典 + 少量规则，不需要标注数据 零训练成本、秒级上线、结果可解释（能告诉你"因为『糟糕』−2.5 所以判负） 只认词不认语境：覆盖不全（新词、网络梗）、反讽必失效
机器学习法
ML / 预训练模型微调		 从大量"文本 + 标签"里统计出语言规律；用 BERT 这类预训练模型时，连上下文一起学 [来源 3][来源 4] 成千上万条人工标注数据 + 训练/调参成本 能学到语境与搭配，在同类数据上准确率明显更高 要标注、要训练；不可解释（说不出为什么）；换个领域容易掉点
大模型法
LLM prompting		 把标签定义和判断规则写进提示，让大模型直接读句子做判断 [来源 6] 几乎不需要标注，只要 API 预算和一份好提示 零标注冷启动、能处理复杂语义与"方面级"、换标签几乎不用重训 贵、慢、批量成本高；结果不稳定（同一输入可能不同输出）[来源 7]

③ 关键：同一句话，三种方法为什么会吵起来？用一句典型的中文短评贯穿一下——「这手机真是绝了，用了一周就黑屏，服气。」

路线它实际"看到"的可能的输出
词典法「绝了」在多数词典里偏正面，「服气」偏中性/正面；「黑屏」可能不在词典里偏正面（错）——它没能力知道这里是在说反话
机器学习法如果训练数据里有类似"先夸后贬"的模式，能学到；若训练集是电影评论，迁移到数码评论会掉点可能负面、也可能中性——取决于训练数据像不像这句话
大模型法整句语义 + 常识 + 提示里的规则（比如提示中写了"注意反讽"）大概率负面；但同样的提示重跑两次，偶尔可能给出不同标签 [来源 7]

结论：三个答案都"有道理"，因为它们回答的其实是三个不同问题。词典法回答"这句话里有多少褒义词/贬义词"，机器学习法回答"这句话在我见过的数据里长得像哪一类"，大模型法回答"作为一个人读这句话，说话人是什么意思"。所以在实际项目里，"哪种方法对"要先定义清楚"我们要的到底是哪一个问题"。

三条路线，从文本到结论的路径不同

词典法：文本 → 查情绪词表 → 叠加否定/程度规则 → 加总分 → 极性
机器学习法：文本 → 标注数据训练 → 模型学到的统计规律 → 极性
大模型法：文本 + 提示里的标签定义 → 大模型直接判断 → 极性

05应用场景（具体例子）

场景：校园二手交易平台「跳蚤市场」App 的运营团队，每天新增约 3000 条用户评价，想自动找出"哪些商品描述和实物不一致"，用来做卖家治理。

  • 谁用：平台运营同学（不会调模型，只会用现成工具）。
  • 什么环节：每天把评价流按"负面 / 正面 / 无关"分类，再从负面里挑出"描述不一致"这一类。

第一步 · 词典法先兜底（当天就能上线）。用现成的情绪词典 + 否定规则跑一遍，0 标注数据、结果能解释。但立刻暴露两个问题：

  • 覆盖不全：「yyds」「绝绝子」「血赚」这些新词不在词典里，全被判成中性。
  • 反讽失效：「卖家描述九成新，真九成新呢，缝都裂了」——「真」是正面词，整句被判正面，方向正好反了。反讽/反话是学术界公认的老大难问题，不是调参能解决的 [来源 5]。

第二步 · 机器学习法补准确率（攒 3 周数据后）。人工标注约 2000 条评价，微调一个 BERT 类模型 [来源 3][来源 4]。效果：同类数据上准确率明显上升，"先夸后贬"的句子也能抓到了。但新的代价出现了：

  • 不可解释：模型说这条是负面，运营同学问"为什么"，答不上来——只能给个概率。
  • 换品类掉点：用"手机数码"评论训出来的模型，直接拿去判"考研资料"的评价，准确率会掉——因为用词习惯完全不同。

第三步 · 大模型法处理长尾（只对疑难句子用）。把「负面 / 正面 / 无关」和「是否属于描述不一致」的定义写进提示，再给 3 个示例，几乎不用标注就能跑 [来源 6]。它对反讽的把握明显好于前两者。但代价也很实在：

  • 贵且慢：3000 条全走 API，按 token 计费，成本远高于本地模型。
  • 结果不稳定：大模型的输出默认是非确定性的，同样输入重跑可能给不同标签；即使设置随机种子也只是"尽力而为"，官方明确说不保证完全一致 [来源 7]。

最终的取舍（这才是这条路线真正的知识点）：不是"选一条最好的"，而是分层用——词典法做全量初筛（快、免费、可解释）；机器学习法覆盖主力品类（准、稳定）；大模型法只处理词典和模型"打架"或置信度低的疑难句子（贵但聪明）。
一句话总结三条路线：词典法赢在"便宜可解释"，机器学习法赢在"准且稳定"，大模型法赢在"不用标注、懂反讽"。

06易混淆 / 使用边界

① 情感分析 ≠ 情绪分类 ≠ 意图识别。情感分析（Sentiment）只分"正/负/中"的极性；情绪分类（Emotion）要分"愤怒/喜悦/恐惧"等具体情绪；意图识别（Intent）问的是"用户想干什么"。三者常被混着说，但输出完全不同。

② 极性 ≠ 强度 ≠ 打分。"有点好"和"非常好"极性都是正面，强度差很远。词典法能顺带给出强度（VADER 的 compound 分数就是干这个的 [来源 1]），但业务上的"打几星"需要另外建模。

③ 反讽/反话是公认难点，别指望靠调参解决。反讽的"字面正面、实际负面"本质上是语用问题，学术界专门把它当作独立任务研究，而不是情感分析的一个小分支 [来源 5]。

④ 领域迁移会掉点，且经常悄无声息。在电影评论上表现优异的模型，换到电商、医疗、校园场景往往明显下降。上线前一定要在你自己的数据上抽一批人工核对。

⑤ 大模型"看起来最聪明"但有非确定性。同一输入重跑可能不同结论，这对需要稳定报表的场景是硬伤；官方文档明确把"完全可复现"列为不保证 [来源 7]。要稳定就得加"输出只有固定几个标签"的强约束，或者干脆用本地模型。

⑥ 否定句和条件句容易被当成"正面"。"不是不好"、"如果修好我就满意了"——字面有褒义词但实际语义复杂。这类句子是词典法的高频翻车点，也是检验机器学习模型是否学到语境的好样本。
