# 配套代码 · 使用说明

> 配合 [`../learning-map.md`](../learning-map.md) 的 **Python 基础阶段（第 1–4 次课）** 使用。
> 每个 `.py` 文件里都有逐行中文注释，遇到不懂的语句先看注释。

---

## 一、怎么把代码跑起来

### 最省事的方式：双击

双击本文件夹里的 **`start.bat`**，然后按提示输入数字选择课次。

它会自动检查你有没有装 Python；没装的话会告诉你去哪下载。

### 另一种方式：命令行

在本文件夹打开终端（按住 Shift + 右键 → 「在此处打开终端」），然后：

```bash
python lesson01_card.py      # 换成你要运行的文件名
```

## 二、四个文件对应哪次课

| 文件 | 对应课次 | 下课成品 | 额外依赖 |
| --- | --- | --- | --- |
| `lesson01_card.py` | 第 1 次课 | 个人名片生成器 | 无 |
| `lesson02_guess.py` | 第 2 次课 | 猜数字小游戏 | 无 |
| `lesson03_wordcount.py` | 第 3 次课 | 英文文章词频统计 | 无 |
| `lesson04_cn_analyzer.py` | 第 4 次课 | 中文文本分析小工具 | **jieba** |

前三个只用 Python 自带的工具箱，装好 Python 就能跑。

第 4 次课需要先装一个库，在终端里运行一次就行：

```bash
pip install jieba
```

> **装之前先看报错**：如果直接运行 `lesson04` 而没装 jieba，你会看到
> `ModuleNotFoundError: No module named 'jieba'`。
> 这不是坏事 —— 报错信息其实就是在告诉你去装 jieba。这正是第 4 次课上半场要练的技能。

## 三、学习建议（重要）

1. **上课时不要复制粘贴。** 照着屏幕一个字一个字敲，敲错也是学习的一部分。
2. **每个文件末尾都有一段「试试看」和「挑战任务」。** 那才是真正让你进步的部分，做完比看懂重要。
3. **改坏了不要紧，直接改回来就行。** 代码是可以随便试的，试错是零成本。
4. **卡住时的顺序**：先看报错信息的最后一行 → 再看文件里的中文注释 → 还不行就问。
5. 每次课下课后，**先不看原文件，把当天的代码默写一遍**。写不出来说明还没真的会。
