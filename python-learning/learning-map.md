## 二、第一阶段：Python 基础（第 1–4 次课 · 6 小时）

### 设计原则

1. **只学"够用的 Python"**。目标不是精通，而是"能读懂、能改、能写小工具"。
2. **上下半场分工固定**。上半场偏"听懂"（讲解 + 演示），下半场偏"跑通"（动手 30 分钟以上）。
3. **每次课都有能运行的东西**。不积压，避免"学了三节课还没跑出结果"的挫败感。
4. **每节课埋一颗 AI 的种子**。语法不悬空，始终指向后面的 AI 应用。

### 第 1 次课：让 Python 开口说话

| 时段 | 内容 | 时间分配 |
| --- | --- | --- |
| 上半场 | 装好环境 + 变量与四种基本数据类型 | 讲解 25′ · 演示 12′ · 动手 8′ |
| 下半场 | 输入输出：写一个个人名片生成器 | 讲解 10′ · 动手 32′ · 讲评 3′ |

- **知识点**：Python 安装与编辑器、`print()`、变量、`int` / `float` / `str` / `bool`、字符串拼接与 f-string、`input()` 与类型转换。
- **下课成品**：输入姓名和年龄，打印「你好，杨国美，你今年 20 岁」。
- **AI 关联**：`input()` 是后面"让用户输入一段话交给模型判断"的最小原型。

### 第 2 次课：让 Python 会判断、会重复

| 时段 | 内容 | 时间分配 |
| --- | --- | --- |
| 上半场 | 比较运算 + `if` / `elif` / `else` 分支判断 | 讲解 22′ · 演示 13′ · 动手 10′ |
| 下半场 | 循环 `for` / `while`：写一个猜数字小游戏 | 讲解 12′ · 动手 30′ · 讲评 3′ |

- **知识点**：比较运算符、布尔逻辑、缩进规则、`if/elif/else`、`for` + `range()`、`while`、`break` / `continue`。
- **下课成品**：猜数字游戏：程序想一个数，你猜，它告诉你大了还是小了。
- **AI 关联**：写"正面词 / 负面词"的 `if` 判断，就是情感分析的雏形。

### 第 3 次课：让 Python 会装东西

| 时段 | 内容 | 时间分配 |
| --- | --- | --- |
| 上半场 | 列表 `list` 与字典 `dict`（AI 的主力容器） | 讲解 25′ · 演示 12′ · 动手 8′ |
| 下半场 | 列表推导式 + 英文文章词频统计 | 讲解 12′ · 动手 30′ · 讲评 3′ |

- **知识点**：列表的增删改查与切片、遍历；字典的键值对与遍历；列表推导式；`sorted()` 排序。
- **下课成品**：丢进一篇英文文章，打印出现次数最多的前 5 个单词。
- **AI 关联**：词频统计就是**词袋模型（Bag of Words）**的手工版，是第 5 次课的直接前置。

### 第 4 次课：让 Python 会用别人的轮子

| 时段 | 内容 | 时间分配 |
| --- | --- | --- |
| 上半场 | 函数 `def` + `pip` 安装并使用第三方库 | 讲解 22′ · 演示 13′ · 动手 10′ |
| 下半场 | 实战：用 jieba 做中文文本分析小工具 | 讲解 10′ · 动手 30′ · 讲评 5′ |

- **知识点**：函数定义与参数、返回值、`import`、`pip install`、读懂报错信息。
- **下课成品**：丢进一段中文，打印总字数、词频前 10。
- **AI 关联**：从英文到中文的对比，会自然引出"为什么中文需要先分词"这个问题，直接指向第 5、7 次课。
- **库的选择**：选用 **jieba**，纯 Python 实现，安装不会卡在编译报错，是零基础最不容易翻车的选择。

## 三、第二阶段：人工智能理论与应用（第 5–13 次课 · 13.5 小时）

### 第 5–7 次课｜机器到底怎么理解文字（原理层）

| 课次 | 主题 | 要点 |
| --- | --- | --- |
| 5 | 文本的数字化 | 分词、词袋模型、TF-IDF —— 把第 3 次课手写的词频统计换成库函数 |
| 6 | 词向量与语义 | 词嵌入、余弦相似度 —— 从"数次数"升级到"用向量表示意思" |
| 7 | 大模型怎么读文字 | Token、上下文窗口、预训练与微调 —— 把之前学的「大模型的上下文」落到实地 |

### 第 8–11 次课｜分类与情感分析（应用层）

| 课次 | 主题 | 要点 |
| --- | --- | --- |
| 8 | 文本分类入门 | 用 sklearn 做垃圾短信识别；理解训练集 / 测试集 |
| 9 | 模型评估与调优 | "准确率"为什么不够用：混淆矩阵、精确率、召回率、过拟合 |
| 10 | 情感分析 · 词典法 | 情感词典 + 规则打分；简单可解释，但覆盖不全、反讽失效 |
| 11 | 情感分析 · 机器学习 | 特征工程 + 朴素贝叶斯 / 逻辑回归；让模型自己从数据里学 |

> **为什么第 8 次课先做垃圾短信识别，而不是直接做情感分析？**
> 因为两者是同一类问题（文本分类），但垃圾短信的标签是客观的"是 / 否"，不会因为主观理解不同而扯皮。先把分类的骨架搭稳，第 10、11 次课换成"正面 / 负面"这种主观标签时，才有余力体会"为什么同一句话不同人判得不一样"。

### 第 12–13 次课｜大模型与综合项目

| 课次 | 主题 | 要点 |
| --- | --- | --- |
| 12 | 调用大模型 API | 提示工程做零样本分类；与词典法、机器学习法三方对比 |
| 13 | 综合项目实战 | 把前十二次课的东西串成一个自己的文本分析小应用 |

## 七、刻意不学的内容（以及为什么）

6 小时学不完 Python。以下内容**主动跳过**，理由是入门阶段的 AI 应用用不上，硬塞只会在细节里迷路：

| 跳过内容 | 理由 |
| --- | --- |
| 类与面向对象（class） | 调用现成的库不需要自己写类；入门阶段用不到 |
| 装饰器 / 生成器 / 迭代器 | 属于语言进阶特性，读源码时才需要 |
| 异常处理（try / except） | 先学会"读懂报错并改代码"，比写异常处理更实用 |
| 多线程 / 异步 | AI 推理本身是瓶颈，入门阶段不涉及并发优化 |
| 虚拟环境 / 包管理进阶 | 第 4 次课会用 `pip install` 即可，够用 |

> 这些内容不是不重要，而是**不在此阶段**。等 AI 应用做到需要工程化时，再回头补。
